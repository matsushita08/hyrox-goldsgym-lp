# Phase 1 検証概要

この文書は公開用の検証概要です。実行ログ、個人パス、認証情報、ローカルの状態ファイルは含みません。

## 検証内容

Node.js v24.21.0で次を実行。再現手順はREADMEに記載しています。

| 検証 | 結果 |
|---|---|
| `npm --prefix ai-dev test` | 40件合格、失敗0、skip0 |
| `npm --prefix ai-dev run lint` | Node構文・末尾空白検査、9モジュール合格 |
| JSON・差分空白検査 | 合格 |
| CLI validate / queue | 入力整合・優先順位・同順位Issue順を確認 |
| サイトコピーへのfixture適用 | 作業コピーのみ変更し、機械検証完了 |
| 適用後中断とresume | 状態を引き継ぎ再検証完了 |
| dry-run | 提案と制限検証だけを実施。変更適用・サイト検証は未実施 |
| 意図的な完了条件不一致 | VERIFICATION_FAILEDで拒否し、失敗報告を保存 |
| 意図的な予算超過 | COST_BUDGET_EXCEEDEDで拒否 |
| 元サイトとの差分 | HTML/CSS/JS・画像資産への変更なし |
| ビルド | 該当なし。静的サイトにビルド工程はない |
| ブラウザ・視覚・外部URL検証 | 未実施 |

テストには入力・対象・優先順位・完了条件の拒否、パス/変更量/予算制限、構文/Lint相当/静的検証の失敗、途中再開、入力や元ソース変更時の拒否、重複・同時実行防止、残留ロック拒否、symlink・余分なscratchファイル拒否、子環境の認証情報非継承、生成JSの非実行を含みます。

OS障害を実際に起こした検証ではなく、残留ロックや破損scratchをfixtureで再現しています。料金取得は未接続で、実料金は `null` と記録します。
